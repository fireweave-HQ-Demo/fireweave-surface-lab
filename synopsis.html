Clinic OS

A clinic fax desk, not a chatbot.

You drop a referral PDF. The system reads it. Rules decide if it is ready. A human hits Looks good. Then a browser writes the chart, books a slot, and logs the follow-up call.

The path

How each step runs

One Temporal workflow, ReferralFlow, owns extract through the call. Prior auth and scribe use the same write gate after a completed referral.

01

Drop the fax

Staff upload a hospital PDF. Same file for the same clinic does not start again.

  1. Bytes land in MinIO. A Temporal run starts as extracting.
  2. We read the official Stanford GI form fields and the NLM lab page: name, birthday, why they were sent, insurance, phone.
  3. Form labels are ignored. A blank hospital template or a junk file says could not read this fax.

02

Rules pick the next step

The card speaks English. Missing pieces never reach the chart.

  1. Ready → Ready for you. Person reviews.
  2. Missing labs or insurance → Send it back, and names what is missing.
  3. Outside the service area → stop. Unknown reason → needs a person.

03

Looks good writes the chart

Nothing hits the record without a human token.

  1. Looks good mints a 15-minute HMAC token. The browser never sees it.
  2. The runner checks the signature and consumes the token. A save without it is refused.
  3. A headless browser types name and birthday on the sandbox chart and clicks Save.

04

Book the slot

Payer decides the doctor and the time of day.

  1. Cigna PPO routes to Dr. Patel in the morning. The next open slot is reserved.
  2. The same browser fill writes provider, day, and slot on the sandbox calendar.
  3. Avery Quinn books 08:00. A full board fails instead of double-booking.

05

Log the follow-up call

Every patient is called. The first line is the disclosure.

  1. The script starts with “This call is automated and recorded.”
  2. A number ending in 0000 is no-answer on the first try, then answered on the second.
  3. This is a recorded result on the session, not a live phone line.

06

Prior auth, if needed

Draft what the payer needs. Submit only when the yellow list is empty.

  1. A completed referral opens as a draft with CPT, diagnosis, and the booked date.
  2. Empty CPT blocks submit. A complete draft is typed into the sandbox payer and returns AUTH-.
  3. Same write gate as the chart. A denial path is not wired yet.

07

Scribe the visit

The visit is text. The note waits for the same yes.

  1. Staff paste a transcript and a name. The desk drafts an H&P.
  2. Looks good mints another token. The runner writes the note onto the sandbox chart.
  3. Audio capture and a live room are not in this build.
